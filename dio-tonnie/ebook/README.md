# 🧾 Resumo do Projeto: eBook "Java: O Caminho do Dev Jedi"

## 🎯 Objetivo

Criar um eBook educativo com **temática Star Wars** que ensina os principais conceitos da **Programação Orientada a Objetos (POO)** em Java 21, focando em:

- **Encapsulamento**
- **Herança**
- **Polimorfismo**

---

## 📘 Títulos Criativos Sugeridos

### 1. **Que a Orientação a Objetos Esteja com Você: Java Edition**
**Subtítulo**: *Domine a força do encapsulamento, herança e polimorfismo.*

### 2. **Java: O Caminho do Dev Jedi**
**Subtítulo**: *Aprenda a usar os princípios da POO como um verdadeiro mestre.*

---

## 📚 Estrutura do eBook (10 páginas)

1. **Introdução** – Jornada Jedi com Java
2. **O Conselho da POO** – Os 3 pilares: encapsulamento, herança e polimorfismo
3. **Encapsulamento** – Protegendo atributos, como um sabre guardado
4. **Herança** – Passando habilidades como um mestre para seu padawan
5. **Polimorfismo** – Um único método, muitos comportamentos
6. **Polimorfismo em Ação** – Exemplo prático de sobrescrita
7. **Modificadores de Acesso** – A hierarquia do controle
8. **Prática Jedi** – Desafio prático com classes
9. **Lado Sombrio da Violação** – Erros comuns e como evitá-los
10. **Conclusão** – O Dev Jedi desperto
